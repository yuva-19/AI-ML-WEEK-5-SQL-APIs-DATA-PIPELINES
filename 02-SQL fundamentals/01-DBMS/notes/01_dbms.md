# Database Management Systems (DBMS)

## What is a DBMS?

A Database Management System (DBMS) is software used to
create, store, retrieve, update, manage, and secure data
in databases.

Examples:
- PostgreSQL
- SQLite
- MySQL
- Oracle
- SQL Server
- MariaDB

## Database vs DBMS

Database:
The actual stored data.

DBMS:
The software that manages the database.

Example:

SQLite → manages → food_delivery.db

PostgreSQL Server → manages → PostgreSQL databases

## SQLite

SQLite is a lightweight, embedded, file-based relational database.

Good for:
- Learning
- Local applications
- Prototypes
- Small projects
- Testing

## PostgreSQL

PostgreSQL is a powerful, open-source, server-based relational
database management system.

Good for:
- Production applications
- Large datasets
- Multiple users
- Concurrent connections
- Data-intensive applications
- Data/ML pipelines

## SQLite vs PostgreSQL

SQLite:
- File-based
- Embedded
- Lightweight
- Simple setup
- Excellent for local projects

PostgreSQL:
- Server-based
- Client-server architecture
- More powerful
- Supports many concurrent users
- Excellent for production systems

## AI/ML Engineer Focus

Learn PostgreSQL deeply enough to:
- Design databases
- Write SQL queries
- Connect Python applications
- Retrieve ML datasets
- Store application/ML data
- Work with production data pipelines

Use SQLite mainly for lightweight/local projects.
