# Introduction to Relational Databases

## 1. What is a Database?

A database is an organized collection of data that can be stored, accessed, managed, and updated efficiently.

Example:
- Customers
- Orders
- Products
- Payments

## 2. Database vs DBMS

### Database
The actual collection of stored data.

### DBMS
Software used to create, manage, access, and manipulate databases.

Examples:
- PostgreSQL
- MySQL
- SQLite
- SQL Server
- Oracle

## 3. Relational Database

A relational database stores data mainly in tables consisting of rows and columns.

Tables can be connected using relationships.

Examples:
- PostgreSQL
- MySQL
- SQLite
- SQL Server
- Oracle

## 4. Non-Relational Database

Non-relational databases do not require data to be organized only in traditional relational tables.

Common structures:
- Documents
- Key-value
- Graph
- Wide-column

Example:
- MongoDB
- Redis
- Neo4j

## 5. Relational vs Non-Relational

Relational:
- Table-based
- Structured data
- Usually uses SQL
- Strongly modeled relationships

Non-relational:
- Flexible data structures
- Can store semi-structured/unstructured data
- Query language depends on the database
- Useful for different scalability and data-modeling requirements

## 6. AI/ML Engineer Relevance

AI/ML systems depend heavily on data.

Typical flow:

Application
→ Database
→ Data Pipeline
→ Data Cleaning
→ Feature Engineering
→ ML Model
→ Prediction

Therefore, an AI/ML Engineer should understand database fundamentals and SQL.

## Must Remember

1. Database = organized collection of data.
2. DBMS = software that manages databases.
3. Relational databases organize data using tables.
4. Non-relational databases use other structures such as documents, key-value, or graphs.
5. SQL is commonly used with relational databases.
6. SQLite is a lightweight relational database engine.
